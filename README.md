## Oblique Strategies — веб‑интерфейс для творческой генерации идей

**Ссылка на развёрнутый проект (GitHub Pages):**  
https://creator-of-masterpieces.github.io/karty-podskazhut/

### Описание проекта

Это веб‑проект, реализующий интерактивную версию знаменитой колоды карт *Oblique Strategies* (создана Брайаном Ино и Питером Шмидтом). Сайт помогает пользователям находить нестандартные решения творческих задач через случайные подсказки‑императивы.

### Ключевые особенности

- **Адаптивный дизайн** («резиновая вёрстка»): корректно отображается на любых устройствах (от смартфонов до широкоформатных мониторов).
- **Две темы оформления**: светлая и тёмная (переключаются кнопкой в шапке сайта).
- **Минималистичный интерфейс**: фокус на тексте карты без отвлекающих элементов.
- **Доступность**: семантическая вёрстка, поддержка клавиатурной навигации.

### Технические детали

- **HTML5** — структура страницы.
- **CSS3** — стили, медиа‑запросы, переходы, переменные для тем.
- **JavaScript** — логика выбора случайной карты, переключение тем, интерактивность.
- **Чистый код** без фреймворков для наглядности учебного примера.

### Как использовать

1. Клонируйте репозиторий:  
   ```bash
   git clone https://github.com/ваш-ник/oblique-strategies.git
   ```
2. Откройте файл `index.html` в браузере.
3. Нажмите кнопку «Новая карта» для получения случайной фразы.
4. Переключите тему через кнопки Светлая/Темная в верхнем углу.

### Структура проекта

```
├── index.html          # Главная страница
├── styles/             # Стили
│   ├── style.css        # Основные стили
│   └── variables.css      # Светлая/тёмная тема
├── scripts/            # JavaScript
│   └── theme-changer.js          # Логика приложения
└── images/             # Декоративные иконки, фото колоды в разных разрешениях, фавиконка
└── .gitignore             # Декоративные иконки, фото колоды в разных разрешениях, фавиконка
```

### Деплой на GitHub Pages

Проект уже развёрнут по адресу:  
**https://creator-of-masterpieces.github.io/karty-podskazhut/**

Чтобы развернуть собственную версию:
1. Перейдите в настройки репозитория (*Settings → Pages*).
2. В разделе *Source* выберите ветку `main` (или `master`) и папку `/root`.
3. Нажмите *Save*. Через 1–2 минуты сайт будет доступен по URL в формате:  
   `https://ваш-ник.github.io/название-репозитория/`
